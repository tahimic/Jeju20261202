# 우리 여행 일정 앱

둘이 링크 하나로 함께 보고 고치는 여행 일정표예요. 로그인은 없고, 일정은 Upstash Redis(Vercel에서 무료로 연결 가능)에 저장돼요.

## 기능
- 처음 열면 제주 애월 2박 3일 일정(12/2~12/4)이 채워져 있어요 (`app/initialTrip.js`)
- 📅 일정 / 🎫 예약(항공·렌터카·숙소) / ✅ 할 일 / 🎒 준비물(분류별 체크리스트, "체크 모두 해제"로 귀가 짐 쌀 때 재사용) 네 화면
- Day별 탭과 시간순 타임라인
- 일정마다 카테고리, 시간, 장소(누르면 구글 지도), 메모, 비용, 링크 입력
- 완료 체크, 날짜별 메모
- 자동 저장, 20초마다 그리고 앱으로 돌아올 때 새로고침 (상대방이 고친 내용 반영)

## 배포 순서

### 1. GitHub에 올리기
1. github.com에서 새 저장소를 만들어요 (예: `trip-planner`, Private 추천).
2. 이 폴더의 파일을 전부 올려요. 저장소 페이지의 "uploading an existing file" 링크로 드래그해도 돼요. `node_modules` 폴더는 올리지 않아요.

### 2. Vercel에서 프로젝트 만들기
1. vercel.com → **Add New… → Project**
2. 방금 만든 GitHub 저장소를 **Import** → 설정은 그대로 두고 **Deploy**를 눌러요.

### 3. 저장소 연결 (둘이 공유하려면 꼭 필요해요)
1. Vercel 프로젝트 화면 → **Storage** 탭 → **Create Database**
2. **Upstash for Redis**를 선택해 무료 플랜으로 만들고, 이 프로젝트에 **Connect**해요.
3. **Deployments** 탭 → 최신 배포의 `⋯` → **Redeploy**를 눌러요. 환경변수를 반영하려면 다시 배포해야 해요.

이 단계 전에는 화면 위에 노란 안내가 뜨고, 일정이 그 기기에만 저장돼요.

### 4. 공유
배포된 주소(예: `https://trip-planner-xxxx.vercel.app`)를 남편분께 보내면 끝이에요.
아이폰은 Safari → 공유 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

## 참고
- ⚙️ 설정에서 '기본 제주 일정 다시 불러오기'를 누르면 처음 상태로 돌아가요. 이미 배포해서 다른 내용을 저장했다면 이 버튼으로 제주 일정을 넣으면 돼요.
- 로그인이 없어서 **주소를 아는 사람은 누구나 보고 고칠 수 있어요.** 주소를 둘만 알고 있으면 돼요.
- 두 사람이 정확히 같은 순간에 고치면 나중에 저장한 쪽이 반영돼요.
